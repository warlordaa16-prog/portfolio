# Arnible Marcus — Portfolio

A personal, developer-focused portfolio site built with semantic HTML, responsive CSS, and lightweight JavaScript.

## Featured projects

- [SaveLink Wallet](https://github.com/warlordaa16-prog/Star-finn) — mobile-first wallet concept for savings, transfers, bills, and mobile money.
- [Urban Nexus](https://github.com/warlordaa16-prog/URBAN-NEXUS-) — smart-city platform concept for mobility, traffic, incident reporting, and urban development intelligence.
- [ClassTrack](https://github.com/warlordaa16-prog/ClassTrack) — mobile-first class attendance and reporting platform.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server.

## GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, and select `main` and `/root`. The site URL is <https://warlordaa16-prog.github.io/portfolio/>.
